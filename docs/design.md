# 课简 iOS 设计说明

第一版（0.1.0）的范围、决策与结构。与 Android 版共享领域概念与默认值，代码独立实现。

## 意图

把课简的课表核心带到 iPhone：周/日视图、课程管理、学期与节次设置、今日概览。先做可靠、可离线使用的单机应用，导入导出与提醒在后续版本加入。

## 目标

- 周/日视图课表，连堂课合并、重叠课分栏
- 课程增删改，单双周与自定义周次，考试类型
- 学期：名称、开学日期、教学周数；多学期切换
- 节次作息：11 节默认模板，逐节起止时间可改
- 今日概览：当前课、下一节、倒计时、完成数
- 外观：主题色、课程配色风格、周起始日、周末显示
- 简体中文 / 繁体中文 / 英文
- 本地 JSON 原子落盘，损坏文件自动备份不覆盖

## 非目标（第一版）

- 学校插件导入、教务系统登录
- 通知、闹钟、提醒
- 课程笔记与备忘录
- 小组件、分享码、AI 识图
- 云同步

## 关键决策

| 决策 | 选择 | 理由 |
| --- | --- | --- |
| 语言与 UI | Swift 6 + SwiftUI | 平台原生，无第三方依赖 |
| 结构 | `CurSimpleCore` 本地包 + App | 领域逻辑可在 macOS 上直接 `swift test`，不依赖模拟器 |
| 存储 | Application Support 下的 `state.json`，原子写入 | 透明、易备份；损坏文件改名为 `state.corrupt-<时间戳>.json` 保留 |
| 周次 | 开学日所在周一为第 1 周锚点，教学周独立于显示起始日 | 与 Android 版语义一致 |
| 课程颜色 | 按课程 id 哈希稳定取色，可单课覆盖 | 与"重装不变色"的体验一致 |
| 节次默认 | 11 节模板（08:00 起单节 45 分钟） | 与 Android 版默认作息相同 |

## 数据模型

- `AppState`：schemaVersion、terms、activeTermID、timingProfiles、preferences
- `Term`：名称、开学日（`yyyy-MM-dd`）、周数、课程列表
- `CourseItem`：id、标题、教师、地点、逐周覆盖（地点/教师/标题）、周次、类型、节次槽、自定义钟点、隐藏、详情、颜色
- `TimingProfile`：节次起止时间与标签键

逐周覆盖与"手动课程按 id 覆盖插件课程"的语义为未来插件导入预留。

## 测试

- `CurSimpleCore`：日历周次、时间解析、冲突检测、出现排序、周网格分栏、配色、持久化（含损坏文件备份），40 个用例
- UI 测试：启动、添加课程、设置页存在性（需要 iOS 模拟器运行时）
